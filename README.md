# StudySphere

StudySphere is a student learning workspace built with React, TanStack Start, Vite, and Convex.

## Development

```bash
npm install
npm run dev
```

## Build and tests

```bash
npm run build
npm test
```

## Configuration

Set `VITE_CONVEX_URL` for the Convex backend. Authentication, email verification, and AI actions also require the appropriate Convex environment variables and service configuration. Do not commit secrets or `.env` files.
